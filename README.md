# ⛰ رادار سيارة البر

نظام يبحث تلقائيًا في **حراج** (ومواقع السيارات الأخرى عبر الروابط) عن سيارة مناسبة للبر والصخور، ويستخرج بيانات كل إعلان، ويقيّمه من 100، ويصنّفه، ويعرض النتائج في **موقع مشترك** مع **تنبيهات تيليجرام** للفرص.

```
GitHub Actions (كل ساعتين)  →  جمع الإعلانات  →  استخراج (قواعد عربية + Claude اختياري)
        ↑                                              ↓
 نموذج «أضف عرض» (Issues)                 تقييم + تصنيف + تتبع السعر
                                                       ↓
                       docs/data/listings.json  →  موقع GitHub Pages  +  تيليجرام
```

## التشغيل لأول مرة

1. **Settings → Pages**: Source = `Deploy from a branch`، Branch = `main`، Folder = `/docs`.
2. **Settings → Actions → General → Workflow permissions**: اختر `Read and write permissions`.
3. **Settings → Secrets and variables → Actions** (كلها اختيارية):
   | الاسم | الفائدة |
   |---|---|
   | `ANTHROPIC_API_KEY` | تحليل ذكي لنص الإعلان + ملخص لكل عرض |
   | `TELEGRAM_BOT_TOKEN` | توكن البوت من @BotFather |
   | `TELEGRAM_CHAT_ID` | رقم المحادثة أو القروب الذي تصله التنبيهات |
4. **Actions → البحث التلقائي → Run workflow** لتشغيل أول بحث.
5. أضف أصدقاءك في **Settings → Collaborators** حتى يقدروا يضيفون عروضًا ويحدّثون الحالات.

## الاستخدام اليومي

- **الموقع**: `https://<اسمك>.github.io/<المستودع>/` — فلاتر، ترتيب، لوحة متابعة، متوسطات السوق، ورسالة جاهزة للبائع.
- **إضافة عرض يدويًا**: زر «أضف عرض» → الصق رابط إعلان أو **رابط صفحة بحث** (حراج، السوق المفتوح، يلا موتور، موتري...). يرد البوت بالتقييم خلال دقائق.
- **تحديث حالة**: زر «تحديث الحالة» في بطاقة العرض، أو تعليق في أي Issue:
  ```
  /status haraj:11192126812 معاينة
  /note haraj:11192126812 البائع نزل لـ 17 الف
  /add https://haraj.com.sa/11192126812/...
  ```
- **تعديل المواصفات**: عدّل `config.yaml` (السعر، السنة، الممشى، الموديلات وأوزانها، كلمات البحث) — يعاد تقييم كل العروض تلقائيًا.

## كيف يُحسب التقييم

| العنصر | الوزن الافتراضي |
|---|---|
| السعر مقابل متوسط السوق والميزانية | 30 |
| ملاءمة الموديل للبر | 20 |
| الحالة (حوادث، ماكينة، فحص، استمارة...) | 15 |
| الممشى | 15 |
| سنة الصنع | 10 |
| القرب من جدة | 10 |

**يُستبعد** العرض إذا تجاوز الميزانية، أو كان أقدم من الحد، أو ثبت أنه غير دبل («دبل غمارتين» تعني كابينة مزدوجة وليست دفعًا رباعيًا)، أو كان للتشليح.
التصنيف: 🟢 فرصة ≥ 70 · 🟡 يستحق السؤال ≥ 50 · ⚪ ضعيف.

## إذا حجب حراج سيرفرات GitHub

يحاول النظام بطلب عادي ثم بمتصفح Chromium. إذا فشل البحث تمامًا يظهر خطأ في Actions. الحل: شغّل الجمع من جهازك (عنوان سعودي):
```bash
pip install -r requirements.txt && python -m playwright install chromium
python scripts/collect.py && git add docs/data && git commit -m "تحديث" && git push
```
أو اربط جهازك كـ self-hosted runner وغيّر `runs-on` في `.github/workflows/collect.yml`.

## الملفات

- `config.yaml` — كل الإعدادات
- `finder/extract.py` — استخراج الموديل والسنة والسعر والممشى والدبل والعيوب من النص العربي
- `finder/score.py` — التقييم والتصنيف
- `finder/sources/` — حراج + محلل عام لأي موقع (Open Graph و JSON-LD)
- `scripts/collect.py` · `scripts/issue_command.py` · `scripts/rescore.py`
- `docs/` — الموقع

## الإضافة والتعديل من الموقع مباشرة (بدون GitHub)

الموقع يتصل بجسر مجاني على Google Apps Script (`bridge/Code.gs`) يحمل مفتاح GitHub بشكل خاص.
بعد نشره ضع رابطه في `docs/config.js` (`window.API_URL = "..."`). بدونه تعمل الأزرار عبر GitHub كما كانت.
